# Руководство по использованию конструктора стратегий

## Запуск конструктора

```bash
streamlit run constructor.py
```

Или с локальной установкой зависимостей:

```bash
pip install streamlit
streamlit run constructor.py
```

## Описание функционала

### 1. Создание стратегии

Конструктор позволяет создавать торговые стратегии с помощью визуального интерфейса:

#### Основные параметры:
- **Название стратегии** - имя для сохранения файла
- **Размер лота** - объем торговой позиции (например, 0.1)

#### Условия выхода (Exit Deal):
- **Stop Loss**:
  - `fixed` - фиксированное значение в пунктах
  - `dynamic` - динамическое значение на основе свечей
  - Значение - количество пунктов

- **Take Profit**:
  - `fixed` - фиксированное значение в пунктах
  - `dynamic` - динамическое на основе свечей
  - `relative` - относительное значение (множитель от SL)

#### Условия входа (Entry Deal):

Стратегия состоит из **шагов** для Buy и Sell направлений:
- Каждый **шаг** содержит одно или несколько **условий**
- Все условия в шаге должны выполниться **одновременно**
- Шаги выполняются **последовательно**

**Пример**: Стратегия Stochastic с 2 шагами для Buy:
1. Шаг 1: Stochastic K < 20 (зона перепроданности)
2. Шаг 2: Stochastic K > Stochastic D (пересечение линий)

#### Типы условий:

1. **Indicators** (Индикаторы):
   - Moving Average (EMA, SMA, WMA)
   - Stochastic Oscillator
   - MACD
   - RSI
   - И другие

2. **Value** (Значение):
   - Фиксированное числовое значение
   - Можно указать в пипсах

3. **Price** (Цена):
   - Ask (цена покупки)
   - Bid (цена продажи)

4. **Candlestick** (Свеча):
   - Open, High, Low, Close
   - Range, Body length, Upper wick, Lower wick
   - Индекс свечи (0 = текущая, 1 = предыдущая)

#### Операторы сравнения:
- `<` - меньше
- `>` - больше
- `=` - равно
- `!=` - не равно
- `>=` - больше или равно
- `<=` - меньше или равно

### 2. Просмотр списка стратегий

На странице "Список стратегий" отображается:

#### Таблица со всеми стратегиями
- **Стратегия** - название файла стратегии
- **is_backtested** - индикатор (✅/❌), прошла ли стратегия бэктест
- **Параметры стратегии** - лот, SL, TP
- **Метрики Buy** - количество сделок, прибыль, винрейт, profit factor
- **Метрики Sell** - количество сделок, прибыль, винрейт, profit factor
- **Последний бэктест** - дата и время последнего бэктеста

#### Возможности:
- **Сортировка** - по любому столбцу (прибыль, винрейт, PF и др.)
- **Порядок сортировки** - по возрастанию или убыванию
- **Детальный просмотр** - развернуть стратегию для подробностей
- **Удаление** - удалить стратегию и её метрики
- **Просмотр JSON** - посмотреть код стратегии

Метрики автоматически сохраняются после каждого бэктеста в `metrics/metrics.json`

### 3. Бэктестирование стратегий

На странице "Бэктест" вы можете:

#### Шаг 1: Выбрать стратегию
- Выберите стратегию из списка созданных
- Просмотрите её параметры

#### Шаг 2: Загрузить данные
Два способа загрузки данных:
1. **Использовать тестовые данные** - автоматически загружает данные из `test_data/EURUSD_M15.csv`
2. **Загрузить CSV файл** - загрузите свой файл с историческими данными

Поддерживаемые форматы CSV:
- **MetaTrader**: Date, Time, Open, High, Low, Close, Volume
- **Стандартный**: Datetime, Open, High, Low, Close, Volume

#### Шаг 3: Настроить параметры
- **Point** - минимальное изменение цены (например, 0.0001 для EURUSD)
- **Spread** - спред в пипсах (например, 15)
- **Направления** - выберите buy, sell или оба

#### Шаг 4: Запустить бэктест
Нажмите кнопку "Запустить бэктест" и получите:

**Основные метрики:**
- Всего сделок
- Прибыльных / Убыточных сделок
- Общая прибыль
- Винрейт (%)
- Максимальная просадка
- Profit Factor
- Средняя прибыль

**Детальные метрики:**
- Полный JSON со всеми расчетными показателями
- Дополнительные аналитические метрики

### 4. Структура сохраненных файлов

#### Стратегии
Стратегии сохраняются в директории `strategies/` в формате JSON.

#### Метрики бэктеста
Метрики сохраняются в файле `metrics/metrics.json` в следующем формате:


## Примеры стратегий

### Пример 1: Простая стратегия на пересечении MA

**Buy условия:**
- Шаг 1: MA(9) > MA(21)

**Sell условия:**
- Шаг 1: MA(9) < MA(21)

**Exit:**
- SL: 50 пунктов (fixed)
- TP: 3x SL (relative)

### Пример 2: Стратегия Stochastic

**Buy условия:**
- Шаг 1: Stochastic K < 20
- Шаг 2: Stochastic K > Stochastic D

**Sell условия:**
- Шаг 1: Stochastic K > 80
- Шаг 2: Stochastic K < Stochastic D

**Exit:**
- SL: 40 пунктов (fixed)
- TP: 2x SL (relative)

## Использование созданных стратегий

После создания стратегии, используйте её в BacktestStrategyProcessor:

```python
import json
import pandas as pd
from traderhub_tradeanalytica import BacktestStrategyProcessor

# Загрузить стратегию
with open("strategies/my_strategy.json", "r") as f:
    strategy = json.load(f)

# Загрузить данные
candles = pd.read_csv("data.csv")

# Запустить бэктест
point = 0.0001
spread = 15 * point
backtest = BacktestStrategyProcessor(
    candles,
    strategy,
    "buy",
    point,
    spread
)

metrics = backtest.process_strategy()
print(metrics)
```
